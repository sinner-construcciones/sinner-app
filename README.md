# Sinner Construcciones · App

Página que publica Netlify (sinnerconstrucciones.netlify.app).
Cada cambio que se sube a la rama `main` se publica solo.

No se suben acá: los datos (.json de carga) ni los scripts de Supabase (.sql).
La clave de `config.js` es la publicable (pública por diseño); la clave secreta nunca va en el código.
